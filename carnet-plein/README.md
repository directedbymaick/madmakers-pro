# Carnet Plein®

- `site/` contient tous les fichiers publics déployés.
- `internal/` contient les livrables, documents juridiques, opérations, ventes et stratégie.
- `tools/` contient les utilitaires de développement propres au projet.

Le site se lance localement depuis la racine du workspace avec :

```powershell
python carnet-plein/tools/dev/serve.py
```
